ChauffIQ Backend API & Services

Modular Cloud Architecture • Node.js 24 • Cloud Functions v2 • Cloud Firestore

• Production Services Active

Environment & Stack

  • Runtime: Node.js 24
  • Platform: Cloud Functions v2
  • Region: asia-southeast1
  • Database: Cloud Firestore
  • Auth: Firebase Identity Platform
  • Messaging: Firebase Cloud Messaging

Security & Protection

  • CORS: Origin Restricted
  • Rate Limiter: Sliding Window (Firestore)
  • Secrets: Google Secret Manager
  • Custom Claims: Server Authoritative
  • Input Validation: Strict Sanitization
  • Logging: GCP Cloud Error Reporting

Architecture

  • Express Gateway: /api/v1/*
  • Cloud Functions: 29 v2 HTTPS Endpoints
  • Controllers: Modular Domain Handlers
  • Services: Business Logic Isolation
  • Middleware: Auth / CORS / RateLimit

Primary API Gateway Endpoints (/api/v1/*)

Method Endpoint Authentication Description
POST /api/v1/auth/register Public (Rate-limited) Register Passenger, Driver, or Family Member
POST /api/v1/auth/login Public (Rate-limited) Authenticate with email and password
POST /api/v1/drivers/register Bearer Token (Driver) Submit driver vehicle and license profile
PATCH /api/v1/drivers/availability Bearer Token (Driver) Toggle online/offline driver availability
POST /api/v1/drivers/location Bearer Token (Driver) Update real-time GPS coordinates
GET /api/v1/drivers/available Bearer Token List available nearby drivers
POST /api/v1/rides/book Bearer Token (Passenger) Request and book a new ride
GET /api/v1/rides/:rideId Bearer Token (Participant) Fetch ride details and real-time status
PATCH /api/v1/rides/:rideId/status Bearer Token (Driver/Rider) Update ride lifecycle (ACCEPTED, ARRIVED, etc.)
GET /api/v1/trips/history Bearer Token Fetch paginated trip history
POST /api/v1/payments Bearer Token Initiate sandbox or card payment
POST /api/v1/ratings Bearer Token Submit ride rating and review
POST /api/v1/notifications/fcm-token Bearer Token Register FCM token for push notifications
GET /api/v1/admin/overview Bearer Token (Admin) Fetch aggregated platform KPIs
